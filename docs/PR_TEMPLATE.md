# Шаблон описания pull request

Claude Code заполняет этот шаблон в конце блока и выводит готовый текст в
сессии. Тимлид создаёт PR командой `gh pr create` с этим описанием, правки —
`gh pr edit` (CLAUDE.md §4, шаг 8). Пустых разделов не бывает: если писать
нечего — так и написать («нет»).

---

## Заголовок

`Блок <ветка без block/>: <что сделано, одной фразой>`

Пример: `Блок move-from-land-monitor: сборщик ЦИАН переехал в свой репозиторий`

## 1. Что делает этот блок

Простыми словами, 2–4 предложения, без названий функций. Что сборщик теперь
умеет или как изменился, чего не было до этого блока.

## 2. Какие кейсы тест-плана закрыты

| Кейс | Название | Тест |
|---|---|---|
| 21.36 | Паузы между запросами | `test_21_36_pause_lower_bound` |

Разделы `docs/CIAN_DATA_FORMAT.md`, на которые опирается блок (если есть).

## 3. В каком порядке читать

Сначала тесты — они говорят, ЧТО должно происходить; потом код — КАК.

1. `tests/test_collector*.py` — на что обратить внимание
2. `collector/<модуль>.py` — на что обратить внимание
3. прочие файлы (`scripts/`, `docs/`), если есть

## 4. Как проверить

Проверки GitHub не работают (кончились минуты Actions, решение Андрея
11.11): единственная проверка — локальный прогон перед push (CLAUDE.md §7).
Команды — абсолютным путём из своего окружения `.venv` (CLAUDE.md §8):

```
/Users/andrei/Documents/Projects/PythonProjects/ads_collector/.venv/bin/ruff check .
/Users/andrei/Documents/Projects/PythonProjects/ads_collector/.venv/bin/ruff format --check .
/Users/andrei/Documents/Projects/PythonProjects/ads_collector/.venv/bin/python -m mypy
/Users/andrei/Documents/Projects/PythonProjects/ads_collector/.venv/bin/python -m pytest -q -n 4 --cov --cov-report=term-missing
```

Сюда обязательно вставляется вывод последнего локального прогона перед push
(итоговые строки каждой из четырёх команд, для pytest — число тестов и
строка покрытия) и sha коммита, на котором он шёл. Сколько тестов было,
сколько стало, все зелёные.

## 5. Что сознательно НЕ сделано

Что осталось за рамками блока и открытые места (отдельного файла заделов в
репозитории нет — они живут здесь и в `docs/process/TEAMLEAD_REPORT.md`).

## 6. Вопросы к Андрею и места, где я не уверен

Каждый вопрос — в формате CLAUDE.md §4а (объяснение, варианты таблицей,
рекомендация, «Меняет план: да/нет»). Вопрос уровня 2, по которому тимлид
пошёл по своей рекомендации, помечен «допущение»; вопрос о данных и формате
папки прогона — ещё и «о данных — ответ до слияния», такие вопросы идут
первыми. Андрей отвечает до слияния, не согласен — правка в этом же PR
(правка логики — круг ревью по шагу 9). Если вопросов нет — «нет». Факт и
предположение различать явно.

## Самопроверка Claude Code перед тем, как отдать блок

- [ ] план блока был согласован до кода
- [ ] два коммита: «тесты» (красные) и «код» (до зелёного); тесты во втором
      коммите не ослаблены
- [ ] все тесты зелёные, включая старые; покрытие 100 %; вывод локального
      прогона вставлен в раздел 4
- [ ] нет сетевых запросов и секретов; тесты не ходят в сеть; числа
      сборщика — в `Settings` и константах контракта `search_page.py`
      (исключения, CLAUDE.md §6: `HTTP_TIMEOUT_S` и `COOKIE_DOMAIN` — в
      `transport.py`, умолчания аргументов запуска `BUDGET`, `WINDOW_HOURS`,
      `RUNS_DIR` — в `cian_collect.py`)
- [ ] в `collector/` только стандартная библиотека, кроме httpx в
      `httpx_transport.py`; правило импортов
      соблюдено (тест 21.78)
- [ ] формат папки прогона не изменён (или есть решение Андрея)
- [ ] имена — по словарю CLAUDE.md §10; комментарии объясняют «почему» и
      ссылаются на кейс или решение
- [ ] у каждого нового модуля есть шапка
- [ ] без попутных правок «заодно»

## Четыре вопроса при ревью

Вопросы к любому читателю кода — ревьюеру и тому, кто откроет код через год; Андрей код в PR не читает.

1. Могу пересказать блок своими словами?
2. Понятно, какой кейс что проверяет?
3. Есть имя или строка, над которой пришлось думать?
4. Можно ли сделать проще?

Если на 3 или 4 ответ «да» — блок возвращается на упрощение. Это дефект
кода, а не читателя.
