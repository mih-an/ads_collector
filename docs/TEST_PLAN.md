# Тест-план сборщика ЦИАН

Проверяемые случаи сборщика: одна строка — один кейс, номер кейса стоит в
имени теста (`test_21_36_…`) и в его docstring. Документ нормативный: код
следует тест-плану, а не наоборот (CLAUDE.md §3). Нумерация «модуль 21»
сохранена с тех пор, как сборщик жил в репозитории land-monitor. Номера PR
(#116–#122), заделы З…, правила E-…/R-… и каталог `data/runs` в этом
документе относятся к репозиторию land-monitor.

## Модуль 21. «Сборщик ЦИАН»

Решения Андрея 10.11 (в репозитории land-monitor, блок block/collector-tests):
тесты → рефакторинг → свой репозиторий для сборщика с тестом-контрактом
формата. Проверяем боевой сборщик, пакет `collector/` (запуск и края —

### Часть В. Сеть: транспорт и запрос страницы

Транспорт (`Transport` в `collector/transport.py`) только доставляет запрос и
приносит ответ как с провода — `HttpReply` (код, заголовки, тело байтами без

`urllib_transport.UrllibTransport` (по умолчанию) и

кейс 21.86 (`tests/test_collector_browser.py`, фикстура `stand`; описание
