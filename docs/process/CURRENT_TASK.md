Задача: block/transport — сменный сетевой транспорт сборщика, обход без «краёв», говорящие имена.
Метка: [ТРАНСПОРТ]

Цель: работа с сетью — за ясным интерфейсом; две живые реализации, каждая в своём файле; тесты логики обхода
не знают ни urllib, ни monkeypatch. Формат папки прогона не меняется (контракт 21.79 и эталонные ночи —
без правки ожиданий). На сервер ничего не выкатывается.

Состав:
1. Транспорт. Интерфейс Transport (typing.Protocol) в своём файле: один метод — GET по адресу с заголовками →
   ответ (код, заголовки, тело) или сетевая ошибка. Тип ответа — там же (сейчас serp.Response).
   Реализации, каждая в своём файле: на urllib (стандартная библиотека, по умолчанию) и на httpx (внешняя
   библиотека — решение Андрея 11.11, вариант Б: «чтобы по-честному»). Выбор — флаг запуска --transport
   (urllib | httpx). Без установленного httpx сборщик с транспортом по умолчанию обязан работать: на сервере
   сборщик идёт голым python3 до выкатки.
2. Наша логика — над транспортом, одна для всех: повторы при сбое сети, разбор сжатия (в т. ч. З167), заголовки
   запроса, вердикты. Каждая реализация транспорта — только «доставить запрос и принести байты».
   Fetcher._do (40 строк, расчёт длительности повторён шесть раз — отчёт PR #1) переписывается здесь.
3. Edges убрать: в обход передаются транспорт (через логику п. 2), часы (Clock: который час, подождать) и
   генератор случайности — отдельными понятными частями. Порядок вызовов случайности не меняется (seed).
4. Имена: Night → Crawl, night.py → crawl.py, NightState → CrawlState и т. п.; serp / get_serp — жаргон
   (Search Engine Results Page) → говорящие имена по смыслу «страница поиска»; точные имена — тимлид
   по словарю проекта, внести в словарь. Имена в файлах на диске (night.log, поле "night" в summary.json,
   метка папки) — формат, не трогать.
5. Тесты:
   - тесты обхода — на фальшивом транспорте со списком ответов, без monkeypatch на сеть и без urllib;
   - каждая живая реализация — своими тестами, общий набор кейсов для обеих: тот же вход → тот же ответ;
     сеть в тестах подменяется (сокет / обработчик библиотеки), наружу не ходит;
   - эталонные ночи — по-прежнему через main, это единственное место проверки «всё вместе».
6. Билет: флаги --cookies и --ua с путями к файлам; без флагов — как сейчас (cookies.txt и ua.txt из папки
   запуска). Андрей держит билет вне репозитория и запускает пробу с Mac сам.
7. README сборщика: как запустить пробу с Mac своим билетом (откуда взять куки и UA в браузере, команда запуска).
